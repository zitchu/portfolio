# US-01.1: Suporte Multilíngue e Navegação Mobile Superior

## 🎯 Objetivo (O que e por quê)
Permitir que usuários de outras nacionalidades compreendam o portfólio através de traduções para INGLÊS e ESPANHOL (mantendo PORTUGUÊS como padrão), e proporcionar uma navegação mais familiar no mobile movendo elementos do footer para uma Top Navbar. A identidade e estética devem continuar rigorosamente as mesmas.

## 🧠 Contexto de Expert (Visão de Marketing/Produto estratégica)
A internacionalização (i18n) atua diretamente na captação de oportunidades estrangeiras. Manter os títulos originais de projetos mostra autenticidade, enquanto a descrição traduzida garante entendimento tecnológico. A navegação no topo no mobile (top navbar) aumenta consideravelmente o acesso aos links principais e as conversões de "contato/download de currículo", por ser o modelo mental padrão dos usuários em sites.

## 📝 Fluxo de Experiência/UX (Passo a passo do usuário)
1. O usuário (tanto mobile quanto desktop) acessa o site e vê a página em Português (padrão) ou no idioma previamente salvo.
2. No Desktop: O usuário visualiza as opções "PT | EN | ES" ao lado do botão de CV na Sidebar.
3. No Mobile: O usuário vê uma barra superior (Navbar fixa) com links e a opção de idiomas, além da ausência dos links no rodapé.
4. O usuário clica em outro idioma. O texto de todo o site (Sidebar, Navbar, Seções e Descrição dos Projetos) muda instantaneamente sem recarregar a página.
5. As larguras e cliques respondem visivelmente a toques no mobile com áreas maiores e sem rolagem horizontal indesejada.

## 📝 Requisitos Técnicos (Arquitetura, DB, Componentes)
- **Estado de Idioma**: Hook/Context React com salvamento da preferência no `localStorage`.
- **Dicionário i18n**: Estrutura contendo UI Text (`uiText.pt`, `uiText.en`, `uiText.es`).
- **Dados dos Projetos**: Modificar as constantes convertendo a string `descricao` em objeto `{ pt, en, es }`. O campo `nome` se mantém inalterado.
- **Componentes impactados**: Sidebar (Desktop), Nova Topbar (Mobile), Contatos, Footer (remover links no mobile).
- **CSS**: Media queries com os breakpoints (mobile < 768px, tablet 768px - 1024px, desktop > 1024px) ajustando tamanhos de toque e prevenindo overflow.
- **Atalho/Link**: Atualizar URL do LinkedIn espalhado no projeto para o endereço novo (https://www.linkedin.com/in/jeanluiz-monteiro/).
