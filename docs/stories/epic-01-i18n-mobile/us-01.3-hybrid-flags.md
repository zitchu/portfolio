# US-01.3: Bandeiras Híbridas na Sidebar (Refinamento Visual)

## 🎯 Objetivo (O que e por quê)
Aperfeiçoar o comportamento e o visual do seletor de idiomas na Sidebar Desktop. O objetivo é criar dois comportamentos de leitura dinâmica:
- A Sidebar deve carregar "Aberta" por padrão em primeira carga. 
- Quando Aberta: Os botões de idiomas devem exibir bandeiras híbridas para Português (Brasil/Portugal) e Inglês (Estados Unidos/Inglaterra), além de manter a versão sólida para Espanhol.
- Quando Fechada (Collapsed): Esconder completamente as bandeiras, deixando as labels reduzidas e centralizadas (PT, EN, ES) fluídas sob um hover padronizado.

## 🧠 Contexto de Expert (Visão de Marketing/Produto estratégica)
Portfólios internacionais costumam ter visitantes de múltiplas culturas. Representar o Português apenas com a bandeira do Brasil ou de Portugal exclui visualmente parte da audiência. O uso de bandeiras cortadas diagonalmente (`clip-path`) é o estado da arte de Design Multidisciplinar UI e resolve isso de forma incrivelmente compacta e visualmente elegante. Omitir as bandeiras no modo recolhido poupa ruído visual e facilita o clique do usuário na versão minimalista.

## 📝 Fluxo de Experiência/UX (Passo a passo do usuário)
1. **Entrada:** Ao carregar a página web, o usuário nota que a Sidebar esquerda está na sua versão extensa (w-40), não encolhida.
2. **Leitura Aberta:** Na base dos nomes, os botões têm miniaturas. Para **PT**, a miniatura é um quadrado 🇧🇷 diagonal 🇵🇹; para **EN**, 🇬🇧 diagonal 🇺🇸; para **ES**, a clássica 🇪🇸.
3. **Hover no Mouse:** O mouse flutua por cima dos botões, passando do tom cinza texto para branco brilhante nativo. O Clique ativa a versão subjacente do Contexto.
4. **Fechamento:** O usuário clica na flecha `<` da sidebar encolhendo-a (`w-20`). Sumariamente as bandeiras somem, e a leitura exibe confortavelmente e centralizados apenas "PT | EN | ES".

## 📝 Requisitos Técnicos (Arquitetura, DB, Componentes)
- **App.js:** Ajuste no estado inicial para `const [isCollapsed, setIsCollapsed] = useState(false);`.
- **App.css:** Adoção de CSS nativo com wrappers `relative` e `absolute` em pareamento com formadores poligonais de `clip-path(polygon(0 0, 100% 0, 0 100%))`.
- **Sidebar.js:** Tratativa condicional na renderização: Renderizar os elementos criados no CSS condicionado ao valor invertido de `isCollapsed`. A blibioteca `flag-icons` injeta as imagens por background CSS.
- Não existem alterações de rotas ou novas bibliotecas.
